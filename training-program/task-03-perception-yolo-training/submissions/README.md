# 📁 Task 03 Submissions

Bu dizin, üyelerin Task 03 için eğittikleri YOLO modelinin metrik grafiklerini ve tespit görsellerini yükleyecekleri alandır.

## 📌 Teslimat Kuralı
1. Bu dizin altına kendi ad ve soyadınızla bir alt klasör açın:
   ```text
   submissions/<ad_soyad>/
   ├── results.png
   ├── test_detection_1.jpg
   ├── test_detection_2.jpg
   ├── data_sample.yaml
   └── README.md
   ```
2. Büyük model ağırlık dosyalarını (`.pt` - 10-50MB) GitHub'a commit etmeyiniz. Sadece metrikleri ve test sonuç görsellerini yükleyin.
3. Yalnızca kendi klasörünüzü `git add` yapıp PR açın.
