# 📁 Task 01 Submissions

Bu dizin, üyelerin Task 01 için hazırladığı sunum ve özet raporlarını yükleyecekleri alandır.

## 📌 Teslimat Kuralı
1. Bu dizin altına kendi ad ve soyadınızla bir alt klasör açın:
   ```text
   submissions/<ad_soyad>/
   ├── sunum.pdf
   └── ozet.md
   ```
2. Başka üyelerin klasörlerine kesinlikle dokunmayın.
3. Yalnızca kendi klasörünüzü `git add` yapıp PR açın.
